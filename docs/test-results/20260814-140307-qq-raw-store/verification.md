# QQ 对话原文安全存储修复验证

## 结论

`QQ_RAW_STORE_FAILED` 的根因是新建 `qq-imports` 命名卷为 `root:root / 0755`，
而后端以 `uid=100(app) / gid=101(app)` 运行。加密主密钥和 QQ Bridge 配置正常，
失败发生在 AES-256-GCM 密文写入目录时。

## 修复

- 当前 UAT 业务卷已精确修正为 `100:101 / 0700`。
- 后端正常镜像与 UAT 预构建镜像都会预创建同属主、同权限的留存目录。
- 新增 `tests/uat/verify-qq-storage-image.sh`，用自建临时卷验证镜像实际挂载行为。
- 已保留修复前镜像回滚标签；未删除 QQ 或 PostgreSQL 业务卷。
