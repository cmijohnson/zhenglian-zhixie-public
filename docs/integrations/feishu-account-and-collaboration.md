# 飞书账号绑定与安全双向协同

英格云是业务主系统。飞书多维表格提供组织内数据协作副本，但客户归属、A/B/C、审核、成单、权限和审计只由英格云决定。

## 启用前提

1. 在组织管理的“飞书多维表格”中完成 App ID、App Secret、Base Token、建表与首次同步。
2. 在飞书企业自建应用中配置与 `FEISHU_OAUTH_REDIRECT_URI` 完全一致的回调地址。
3. 正式环境必须使用可信 HTTPS。内网试验只有在 `FEISHU_ALLOW_INSECURE_OAUTH_PILOT=true` 时允许 RFC1918 HTTP 地址。
4. 在飞书开放平台为应用配置用户基础身份、目标 Base 读写/管理和多维表格记录变更事件权限，并发布应用版本。
5. 确认目标 Base 只分享给有权查看完整客户资料的组织成员。

每个组织的双向协同开关默认关闭。服务端长连接组件默认可用；完成上述检查后，依次启用客户同步、账号绑定和安全双向协同。紧急停机时可设置 `FEISHU_LONG_CONNECTION_ENABLED=false`，不会删除英格云或飞书数据。

## 字段边界

- 可直接双向编辑：昵称、手机号、微信、QQ、学校、高中、专业、年级、城市、生源地、需求摘要、关注方向和普通标签。
- 受控操作：客户状态、意向、紧迫度和下次跟进时间，通过飞书协同工作台提交。
- 只读：客户 ID、姓名、A/B/C、负责人、团队、协作者、可见范围、归档、成单、版本和同步字段。

飞书删除已同步记录不会删除英格云客户。系统会新建替代 Record、更新稳定映射并写入异常审计。飞书新增记录会成为 24 小时客户草稿，必须经过查重和成员确认才会正式建档；确认后复用原飞书 Record，不会重复新增客户行。

安全字段成功写入英格云后，系统立即把新的实体版本及规范化字段回写原 Record。这样连续编辑不会因为飞书仍持有旧版本而产生假冲突；数据库触发器产生的后续出站任务会根据新快照哈希自动跳过。

## 身份与登录

绑定键为 `tenant_key + user_id -> membershipId`。姓名、手机号、用户名、飞书显示名和 `open_id` 都不能用于自动绑定。用户离开组织、成员停用、账号停用或绑定被撤销后，飞书登录和协同写入立即失效。密码登录始终保留。

系统只在 OAuth 回调期间使用飞书用户 Access Token，身份读取完成后立即丢弃。数据库只保存绑定的稳定标识、一次性意图哈希和审计元数据。

## 运维与回滚

- 管理页应持续显示事件连接、最近事件、冲突、拒绝和失败数量。
- 事件按飞书 event ID 去重；出站事件通过版本与快照比对自动忽略，防止同步回环。
- 暂停时先关闭入站协同，再关闭长连接和出站 Worker；不删除飞书记录或英格云数据。
- App Secret、应用 Token、用户 Token和客户字段内容不得进入日志、审计详情或测试快照。
