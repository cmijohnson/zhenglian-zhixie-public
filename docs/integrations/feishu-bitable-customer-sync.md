# 飞书多维表格客户同步运维手册

## 能力边界

- 英格云是唯一数据源，飞书侧修改标准字段会在后续同步或一致性校验时被覆盖。
- 飞书自定义字段不在系统字段映射中，不会被英格云写入或删除。
- 同步包含归档客户、私有客户以及完整手机号、微信号和 QQ 号。目标 Base 只能共享给获准查看这些资料的人员。
- 每个英格云组织只能配置一个独立集成和一个目标 Base；组织身份由登录会话推导。
- 本功能只访问 `https://open.feishu.cn`，不接受自定义 API 主机或跨主机重定向。

## 飞书侧准备

1. 在飞书开放平台创建企业自建应用并完成发布审核。
2. 为应用开通多维表格查看、编辑和管理权限。
3. 创建一个专用多维表格 Base，不需要手工建立客户数据表。
4. 在 Base 的文档应用管理中添加该自建应用，并授予编辑权限。
5. 从 Base 地址取得 App Token。不要把 App Secret 放入 URL、聊天、日志或仓库。

## 服务端配置

生成至少 32 字节的随机主密钥并以 Base64 注入：

```text
FEISHU_INTEGRATION_MASTER_KEY=<repository-external-base64-key>
```

该密钥只用于 AES-256-GCM 加密 App Secret，必须与数据库备份一起保管。丢失后已有密文无法恢复，只能由管理员重新录入飞书 App Secret。正式环境不得使用示例值。

## 管理端启用步骤

1. 进入“组织管理 → 飞书多维表格”。
2. 填写 App ID、App Secret 和目标 Base App Token。
3. 阅读并勾选私有客户及完整联系方式同步风险确认，然后保存。
4. 点击“测试连接”。
5. 点击“初始化/修复表结构”。系统创建“英格云客户档案”及标准字段，并保存字段 ID。
6. 启用集成。
7. 点击“预览首次同步”，核对总客户数、私有客户数和归档客户数。
8. 再次确认后启动首次同步。系统先写入 10 条作为自动协议预检，通过后继续全部客户。

App Secret 保存后不会回显。字段允许在飞书侧改名，但不得删除或改变类型；检测到必要字段缺失或类型不兼容时，系统会暂停同步，管理员需要修复表结构并重新启用。

## 调度与故障处理

- 每小时第 5 分钟合并并发送客户变更，每批最多 100 条。
- 每天北京时间 02:30 执行全量一致性校验。
- 临时错误最多重试 5 次并指数退避；终态失败可在管理页人工重试。
- 归档只更新“是否归档”，不会删除飞书记录。
- 更换 App ID 或 Base Token 会终止旧目标上的活动同步并清空旧目标映射，不会删除旧 Base 中已经存在的数据。
- 回滚应用时先暂停集成，再恢复旧镜像；不要删除飞书记录或英格云业务数据。

## 正式启用门禁

- Flyway 从空库和正式库副本升级通过。
- 后端、前端及飞书契约测试零失败、零跳过。
- 使用专用测试应用、独立 Base 和合成客户完成连接、建表、10 条预检、全量、变更、归档和失败重试闭环。
- 正式启用前完成 PostgreSQL 备份、校验和恢复验证。
- 审计和应用日志中不得出现 App Secret、Access Token 或完整客户快照。
