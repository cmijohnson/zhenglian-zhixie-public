# ADR 0002: AI 使用自有 Provider 边界

- 状态：已接受
- 日期：2026-07-19

## 决策

MVP 不引入 Spring AI。业务代码仅依赖 `AiProvider`，提供一个 OpenAI 兼容适配器和一个无密钥时启用的禁用适配器。

## 安全边界

AI 不得执行任意 SQL。客户数据先通过 Java 权限范围查询，再按用途裁剪。解析结果只生成草稿，用户确认后才能由普通业务服务写入。AI 不可用时，其他业务仍须正常运行。

## 后果

更换模型或未来评估 Spring AI 时，只替换 infrastructure 适配器，不改变客户和权限模块。
