# 英格客户云 Agent MCP 员工接入手册

## 1. 用途与地址

英格客户云 MCP 允许员工在支持 MCP 2025-11-25、Streamable HTTP 和 OAuth 2.1 的 Agent 中查询、创建和更新本人有权访问的业务数据。

- 正式 MCP 地址：`http://101.43.22.42:38080/mcp`
- 授权方式：OAuth 2.1 Authorization Code + PKCE S256
- 身份原则：Agent 始终以当前员工身份执行，不能选择或伪造组织
- 会话：空闲 30 分钟过期；同一授权最多 5 个并发 MCP 会话

> 当前地址按负责人在 2026-07-22 的明确授权使用 HTTP，传输内容不会被 TLS 加密。只可在可信网络及允许远程 HTTP MCP 的 Agent 中使用；不要复制 Token、客户资料或 AI 输出到公共 Agent 会话或日志中。

## 2. 首次连接

1. 在 Agent 的 MCP 服务器设置中选择“Streamable HTTP / 远程 MCP”。
2. 填入 `http://101.43.22.42:38080/mcp`，不需要手工填写 Access Token。
3. Agent 会自动读取 OAuth 元数据并打开英格客户云登录页。
4. 登录后核对客户端名称、精确回调地址和申请的 Scope，再点击“同意授权”。
5. 返回 Agent 完成连接，通过“我的 Agent”页检查客户端、Scope、最近使用和到期时间。

### QwenPaw（问候）接入

QwenPaw 1.1.12 的 OAuth 回调会被其自身登录中间件拦截，当前使用个人 Bearer 兼容配置：

1. 登录英格客户云并进入“我的 Agent”。
2. 点击“生成问候连接配置”，复制页面一次性显示的完整 JSON。
3. 先在 QwenPaw 左上角选择目标智能体，再进入“工作区 → MCP → 创建客户端 → JSON”导入。
4. 启用“英格客户云”，通过“工具列表”和只读工作台查询完成验证。

个人令牌有效期为 30 天，重新生成会立即撤销上一份令牌。完整步骤、安全要求和 `Session terminated` 排查方法见 [QwenPaw 连接英格客户云教程](./qwenpaw-connection-guide.md)。

可申请的 Scope：

| Scope | 含义 |
| --- | --- |
| `yingge.read` | 查询有权可见的客户、任务、内容、日报和统计 |
| `yingge.write` | 在角色权限内创建或更新业务数据 |
| `yingge.ai` | 使用管理员已开启的智能助手 |
| `yingge.admin` | 组织管理员工具；普通员工即使申请也不会获权 |

Scope 只是上限，服务器每次调用都会重新检查账号状态、角色、团队和资源可见性。

## 3. 日常使用示例

可以用自然语言要求 Agent：

- “查询我负责的 2026 级、示例大学、高意向客户，按最近沟通时间倒序。”
- “先精确查重，如果没有重复，创建客户并在明天 10:00 创建跟进提醒。”
- “给客户记录今天的微信沟通，将状态改为跟进中，并添加标签。”
- “查看我的任务，将已完成的任务提交验收。”
- “根据今天的客户跟进生成日报草稿，给我确认后再提交。”

对创建、更新等写操作，Agent 应为每个逻辑操作重用同一 `idempotencyKey`；网络重试不会重复创建数据。

## 4. 人工确认操作

客户归档、任务关闭/删除、公告归档、成员停用/删除、团队删除、注册码停用和组织 AI 配置变更不会直接执行。

1. Agent 首次调用返回 `approvalId`和确认页。
2. 登录英格客户云，在“我的 Agent”或确认链接中查看操作对象和影响。
3. 5 分钟内批准或拒绝。批准后让 Agent 重试同一参数并携带 `approvalId`。
4. 确认单只能使用一次，更改参数、超时或更换客户端均需重新确认。

## 5. 撤销与安全

- 在“我的 Agent”中可随时撤销单个客户端授权，Access Token 和 Refresh Token 立即失效。
- 修改密码、账号停用或成员关系失效后，已发 Token 也会立即失效。
- 不要在聊天中要求 Agent 显示 Token、AI 密钥或其他员工无权访问的数据。
- 如果 Agent 请求与预期不符，保留结果中的 `traceId`，并联系管理员查询脱敏审计记录。

## 6. 当前边界

首版不通过 MCP 传输 CSV/XLSX，不提供登录、注册和修改密码工具，不允许通过 MCP 写入 AI API 密钥。
