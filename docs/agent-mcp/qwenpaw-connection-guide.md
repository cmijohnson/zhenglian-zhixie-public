# QwenPaw 连接英格客户云 MCP 教程

> 适用版本：QwenPaw 1.1.12  
> 英格客户云：`http://127.0.0.1:8080/`  
> QwenPaw：`http://127.0.0.1:8088/`  
> MCP 服务地址：`http://127.0.0.1:38080/mcp`

## 1. 连接后可以做什么

连接成功后，QwenPaw 可以在当前登录员工的权限范围内调用英格客户云功能，包括：

- 查询工作台、客户、沟通时间线和提醒。
- 创建或更新客户、沟通记录、提醒和任务。
- 查询每日汇报、内容任务、内容圈子和公告。
- 由团队长或管理员审核线索、任务和内容。
- 查询团队数据、成员、团队和审计信息。

MCP 不会扩大员工权限。客户可见范围、团队范围、角色权限以及危险操作确认仍由英格客户云服务端检查。

## 2. 连接前准备

开始前请确认：

1. 可以正常登录英格客户云。
2. 可以正常登录 QwenPaw。
3. 已在 QwenPaw 左上角选择需要使用 MCP 的智能体，例如“英格业务智能体”。
4. 不要在聊天、截图、群聊或公开文档中发送个人令牌。

> QwenPaw 的不同智能体拥有相互独立的 MCP 配置。必须先选择正确的智能体，再导入连接配置。切换到其他智能体后，需要为那个智能体单独配置。

## 3. 在英格客户云生成连接配置

1. 打开 `http://127.0.0.1:8080/` 并登录自己的账号。
2. 在左侧导航栏进入“我的 Agent”，也可以直接访问：

   `http://127.0.0.1:8080/agent`

3. 找到“问候兼容连接”区域。
4. 点击“生成问候连接配置”。
5. 阅读确认提示并点击确定。
6. 页面会显示一份 JSON 配置和到期时间。
7. 点击“复制完整 JSON”。

生成规则：

- 个人令牌有效期为 30 天。
- 令牌只显示一次，刷新页面后不再显示。
- 重新生成会立即撤销上一份问候兼容令牌。
- 令牌继承当前账号的组织、角色、团队和客户可见范围。

生成出的 JSON 结构如下。下面只是格式示例，不能直接使用：

```json
{
  "mcpServers": {
    "yingge_mcp_personal": {
      "name": "英格客户云",
      "description": "以当前员工身份访问英格客户云业务功能",
      "transport": "streamable_http",
      "url": "http://127.0.0.1:38080/mcp",
      "headers": {
        "Authorization": "Bearer <系统生成的个人令牌>"
      }
    }
  }
}
```

## 4. 在 QwenPaw 导入 MCP

1. 打开 `http://127.0.0.1:8088/mcp` 并登录。
2. 在左上角确认当前智能体是需要使用英格客户云的智能体。
3. 在左侧进入“工作区 → MCP”。
4. 点击右上角“创建客户端”。
5. 选择“JSON”导入方式。
6. 粘贴刚才从英格客户云复制的完整 JSON。
7. 点击“创建”或“保存”。
8. 确认列表中出现“英格客户云”，状态为“Remote 已启用”。

如果已经存在 `yingge_mcp_personal`：

- 不要再创建同名或重复客户端。
- 使用编辑/更新方式替换原有 `Authorization` 请求头。
- 更新后将客户端停用一次，再重新启用，并等待 5～10 秒完成热重连。

### 手工填写方式

如果 JSON 导入不可用，可以手工创建：

| 字段 | 内容 |
| --- | --- |
| 客户端 Key | `yingge_mcp_personal` |
| 名称 | `英格客户云` |
| 类型 | `Remote` |
| Transport | `streamable_http` |
| URL | `http://127.0.0.1:38080/mcp` |
| Header 名称 | `Authorization` |
| Header 内容 | `Bearer <系统生成的个人令牌>` |
| 状态 | 启用 |

`Bearer`、一个半角空格和令牌三部分都必须保留。

## 5. 验证是否连接成功

### 5.1 检查工具列表

1. 在“英格客户云”客户端卡片上点击“工具列表”。
2. 页面应显示英格客户云工具，而不是错误提示。
3. 当前版本正常情况下可看到 70 个工具。

工具列表示例：

- `yingge_dashboard_get`
- `yingge_customer_search`
- `yingge_customer_get`
- `yingge_interaction_list`
- `yingge_reminder_list`
- `yingge_task_list`
- `yingge_content_overview`

### 5.2 做一次只读测试

进入 QwenPaw 聊天，发送：

```text
只读查询英格客户云工作台概览，告诉我当前权限范围内的客户和提醒统计。
不要创建、修改、归档或删除任何数据。
```

检查结果：

- QwenPaw 应调用 `yingge_dashboard_get`。
- 返回内容应符合当前员工的角色和团队范围。
- 不应出现其他团队或无权查看的私有客户。

### 5.3 测试客户搜索

可以继续发送：

```text
只读搜索我有权查看的客户，返回前 5 条，并显示客户姓名、负责人和最近跟进时间。
不要修改任何数据。
```

## 6. QwenPaw 1.1.12 的注意事项

QwenPaw 1.1.12 的 OAuth 回调会被其自身登录中间件拦截，因此英格客户云为该版本提供个人 Bearer 兼容配置。

- 使用“我的 Agent → 生成问候连接配置”生成 JSON。
- 不需要点击客户端卡片上的“点击授权”。
- 卡片仍显示“点击授权”不代表连接失败，以“工具列表能否正常打开”为准。
- 不要把个人令牌保存到聊天记录、知识库、截图或公开代码仓库。

## 7. 常见故障处理

### 7.1 `Session terminated`

按以下顺序处理：

1. 确认 QwenPaw 左上角选择的是正确智能体。
2. 确认“英格客户云”位于这个智能体的 MCP 列表中。
3. 将该客户端停用，等待 2～3 秒后重新启用。
4. 等待 5～10 秒，再打开“工具列表”。
5. 如果仍失败，在英格客户云重新生成配置，并更新当前智能体原有客户端的 `Authorization` 请求头。
6. 刷新 QwenPaw 页面后再次检查。

最常见原因是：配置被导入到了另一个智能体，或者当前智能体仍在使用已经撤销的旧令牌。

### 7.2 `401`、`invalid_token` 或突然掉线

可能原因：

- 30 天个人令牌已经到期。
- 在英格客户云重新生成过配置，旧令牌已立即撤销。
- 账号被停用、角色或成员关系失效。
- 修改密码后旧授权失效。

处理方法：

1. 登录英格客户云。
2. 进入“我的 Agent”重新生成问候连接配置。
3. 在正确的 QwenPaw 智能体中更新原客户端。
4. 停用—启用客户端后重新验证工具列表。

### 7.3 工具列表为空或一直连接中

- 检查客户端是否已启用。
- 检查 Transport 是否为 `streamable_http`。
- 检查 URL 是否完整包含 `/mcp`。
- 检查 Header 名称是否为 `Authorization`。
- 检查 Header 内容是否以 `Bearer ` 开头。
- 等待 10 秒后重试；不要连续创建多个重复客户端。

### 7.4 能看到工具，但调用被拒绝

这通常不是连接故障，而是服务端权限检查结果。

- 成员只能访问自己负责、团队可见或明确共享的客户。
- 团队长可以访问本团队数据，但不能修改成员团队归属等管理员专属设置。
- 管理员可以在组织范围内查询和管理数据。
- 危险操作可能返回人工确认链接，必须在英格客户云中批准后再重试。

### 7.5 浏览器提示地址“不安全”

当前 MCP 使用 HTTP 地址，通信没有 TLS 加密，只应在可信网络和受控 QwenPaw 实例中使用。不要通过公共网络转发令牌或业务数据。

## 8. 更新、撤销和到期

### 更新连接

重新生成配置后，应更新原有 `yingge_mcp_personal`，避免同一智能体内出现多个重复连接。

### 撤销连接

1. 登录英格客户云。
2. 进入“我的 Agent”。
3. 在“已授权客户端”中找到对应授权。
4. 点击“撤销”。

撤销后，QwenPaw 中保存的旧令牌会立即失效。随后可以在 QwenPaw 中停用或删除相应客户端。

### 到期前续期

个人令牌不会自动续期。建议在到期前重新生成配置并更新 QwenPaw 客户端。

## 9. 安全要求

- 每位员工使用自己的英格客户云账号生成配置。
- 不多人共用同一个个人令牌。
- 不在 Markdown、聊天、工单或截图中记录真实令牌。
- 不把 `Authorization` 请求头提交到 Git。
- 发现令牌泄露时立即在“我的 Agent”中撤销或重新生成。
- 写操作前先让 QwenPaw说明将要修改的对象和内容。
- 归档、删除、团队调整等高风险操作必须经过人工确认。

## 10. 管理员排查时需要的信息

联系管理员时只提供：

- 发生时间。
- QwenPaw 当前智能体名称。
- MCP 客户端 Key：`yingge_mcp_personal`。
- 页面错误信息。
- 业务接口返回的 `traceId`（如有）。

不要提供个人令牌、账号密码、客户完整资料、数据库密码或 AI 密钥。
