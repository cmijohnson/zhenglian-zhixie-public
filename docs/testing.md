# 自动化测试基线

最近一次完整验证：2026-07-20。后端使用 Java 21、PostgreSQL 18.4 Testcontainers；前端使用 Vitest、Vue Test Utils 和 Vite。测试数据库均为临时容器，测试结束自动清理，不连接生产 PostgreSQL。

正式规模的贯穿式业务、权限、性能、迁移和容灾验收步骤见 [正式大业务全流程测试方案](formal-business-full-process-test-plan.md)。

## 大数据 Mock 规模

- 2 个组织、2 个团队、管理员/主管/成员/只读者等多角色账户。
- 主组织 600 个客户，隔离组织 40 个客户，覆盖私有、团队、组织可见和归档状态。
- 1,200 条沟通记录、500 余条提醒以及大量仪表盘和审计数据。
- CSV 导入 220 行：210 行合法、10 行非法；另含 XLSX 预览、CSV/XLSX 导出和时间线导出。
- 三种任务分发：强制性、派发性、自领取性；覆盖新成员自动补发、成果提交、退回、验收、关闭和双线程争抢单名额。
- 120 条自媒体内容，覆盖小红书/抖音每日上限、原创声明、方向启停、质量审核、指标更新、成员进度、圈子 6 页完整加载、关键词/发送人筛选和权重排序。
- 多成员日报，覆盖 26 级新增有效线索自动计算、团队范围、组织范围和未来日期限制。
- 注册码覆盖管理员生成、明文一次性显示、数据库遮罩列表、CSRF、真实姓名必填、弱密码登录、团队候选列表、必选团队加入、单次码耗尽、固定成员角色、普通成员越权和强制任务自动补发。
- 团队长覆盖单团队唯一约束、负责人未显式填写团队的私有客户、团队内全员可见、跨团队隔离、换任后旧 Session 失效以及角色回收。
- 团队长只能审核本团队的有效线索、工作任务和内容任务，可发布并管理自己发布的公告，不能修改成员角色、团队归属、注册码或内容方向。
- 管理员成员删除覆盖“有负责客户必须先转移”、提醒接收人同步转移、账号软停用；团队删除覆盖成员账号不受影响、团队关系解除和历史数据保留。
- Session 测试验证服务端与持久 Cookie 的默认有效期均为 30 天。

## 覆盖链路

- 登录、退出、注册码注册、Session 持久化、修改密码、CSRF、错误信封和角色矩阵。
- 组织、成员、团队、租户隔离、客户数据范围，以及管理员/团队长的团队数据筛选边界。
- 客户建档、查重覆盖、字典、标签、沟通事务、提醒状态和归档。
- Dashboard、分页筛选、导入导出、迁移 dry-run、Flyway 从空库迁移。
- 内容任务、内容圈、日报、任务分发、并发领取、公告发布/归档/阅读权限、审计、OpenAPI、健康检查和无密钥 AI 降级。

## 执行命令

```bash
cd backend
mvn test

cd ../frontend
npm run check
npm run test:unit
npm run build
```
