# 绩效中心使用与管理手册

## 1. 功能定位

绩效中心以“审核通过的业务事实 + 不可变积分流水”为唯一计分口径，独立于每日汇报。员工在 `/performance` 申报交流和活动，管理员在 `/admin/performance` 配置规则、审核、人工给分并完成每日结算。

系统默认采用 `Asia/Shanghai` 时区、周一至周五计分、每日 baseline 14 分、09:00 开放、22:00 截止。默认普通交流 1 分、深度交流 2 分，活动预置 `50 人及以上 / Pro / 8 分` 示例档次。管理员创建的规则只能从未来日期生效，旧版本和已结算历史不会被覆盖。

## 2. 员工操作

### 2.1 查看今日绩效

进入“每日执行 → 绩效中心”，页面显示：

- 今日已得分、baseline、差额和最终净分；
- 业务分、后勤分和纠错分构成；
- 申报开放时间、待审核数量和深度交流审核数量；
- 今日积分流水、本月个人趋势和所在团队月度排行。

未被管理员加入绩效计算的账号只能查看团队排行，不能申报。`VIEWER` 角色即使被错误加入，也不能执行写操作。

### 2.2 申报交流绩效

1. 先在客户详情中真实记录一条沟通。
2. 在绩效中心选择该沟通记录，并选择“普通交流”或“深度交流”。
3. 上传 1–3 张 JPEG、PNG 或 WebP 证据，每张不超过 5 MB。
4. 提交审核。

一条沟通只能产生一条绩效申报；同一客户当天存在多条不同沟通时可以逐条申报。管理员可批准、驳回或重新认定类型。只有批准后才写入积分流水。

### 2.3 发起和完成活动

员工填写活动日期、名称、目标、预计参与人数和执行说明并提交立项。管理员批准后，总负责人在活动记录中填写实际参与人数、上传成果证据并提交。管理员核定人数档次后，将档次总分分配给参与绩效的成员。

分配以 0.5 分为最小单位，所有成员分配合计必须与档次总分完全一致。

## 3. 管理员操作

### 3.1 参与人员

在“参与绩效人员”中选择成员和开始/结束日期。参与周期不能重叠。停用账号不会进入当天及未来结算，历史积分和当时团队归属保留。

### 3.2 规则版本

创建规则时可配置：

- baseline；
- 每天、指定星期和补充/排除日期；
- 申报开放及截止时间；
- 未达标仅标记，或扣除差额；
- 普通/深度交流分值和每日上限；
- 连续、不重叠的活动人数档次。

生效日期必须晚于当天。同一生效日期只能存在一个版本。

### 3.3 审核与人工分

交流审核必须查看私有证据。驳回时必须填写原因；批准时可按申报类型入账，也可改认普通或深度交流。

基础后勤分只能为非负的 0.5 倍数，应填写事项和原因，可附证据。纠错分允许正负，但必须关联原积分流水；系统不会编辑或删除旧流水，而是增加一条冲正记录。

### 3.4 每日结算

每日状态依次为 `OPEN → REVIEWING → SETTLED`。截止后进入审核阶段；存在待审核交流、未处理活动时不能结算。结算后保存当日规则、baseline、各类得分、差额和最终净分快照。

如需补录，管理员填写原因后重开。重开会把上一版快照标记为历史修订并完整保留，同时继续保留业务积分流水；处理完成后必须再次结算生成新修订。结算、重开及审核操作均写入审计日志。

### 3.5 汇总与导出

管理页可按团队、成员和日期查看月度排行及每日得分构成，并导出 XLSX 明细。组织范围始终由登录身份推导，接口不接受客户端传入的 `organizationId`。

## 4. 每日汇报联动

成员被纳入绩效且规则已经生效的日期起，每日汇报中的“深度沟通人数”变为只读，自动统计已审核通过的深度交流，并显示待审核数量。未参与绩效的成员以及启用日前的历史日报继续使用原手填值，不做追溯改写。

## 5. 权限说明

| 角色 | 本人明细/申报 | 团队排行 | 团队成员汇总 | 规则/审核/给分/结算 |
| --- | --- | --- | --- | --- |
| ORG_ADMIN | 是 | 全组织 | 全组织 | 是 |
| TEAM_MANAGER | 是 | 管理团队 | 管理团队 | 否 |
| MEMBER | 是 | 所在团队 | 否 | 否 |
| VIEWER | 否 | 所在团队 | 否 | 否 |

证据文件不会生成公开地址。员工只能读取自己的证据，组织管理员可读取本组织证据；跨组织、随机 ID 和无权限访问统一返回拒绝或不存在。

## 6. Agent / MCP

绩效结构化查询、申报、审核和结算已登记到 MCP 工具目录，并继续继承当前员工的 OAuth Scope、角色和组织边界。证据图片属于文件传输能力，不能通过 JSON/MCP 内嵌上传，必须在网页完成。
